PINS view

Prototypes exploring what the Planning Inspectorate (PINS) sees of a local plan, from checking its progress before submission to examining it. These are for inspectors rather than LPA staff, so each one uses its own header without the site's internal navigation. Pick one to try it out.

Current prototypes

These are the most recent prototypes we've developed. We'll be testing these over the next few weeks.

Examination - inspector view

What an independent planning inspector sees when examining a submitted local plan.

User needs

Ex1.1 As a planning inspector I need to quickly understand how policies were formed so that I can quickly start to understand the key issues to surface during Examination hearings

Ex1.2 As a planning inspector I need to see the related evidence, respresentations and requirements so that I can assess whether a policy is sound

Gateway 2 progress check

How an independent planning inspector can check the progress of a submitted local plan's chapters and evidence base.

User needs

Ex1.3 As a planning inspector I need to quickly understand the overall progress of a local authority so that I can focus on where I can give feedback.

Ex1.4 As a planning inspector I need to see the what is planned to be worked on further so that I can assess whether it will be sufficient at examination.
